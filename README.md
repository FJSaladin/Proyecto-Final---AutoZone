## 📋 Descripción

AutoZone es una aplicación móvil desarrollada con Flutter que centraliza toda la información relacionada con tus vehículos en un solo lugar. Desde el seguimiento de mantenimientos hasta un foro comunitario para entusiastas del mundo automotriz.

## ✨ Funcionalidades

| Módulo | Descripción |
|--------|-------------|
| 🚘 **Registro de vehículos** | Agrega y administra múltiples vehículos con su información detallada |
| 🔧 **Seguimiento de mantenimientos** | Historial y recordatorios de servicios (aceite, frenos, filtros, etc.) |
| ⛽ **Control de combustible** | Registro de cargas y cálculo de consumo por kilómetro |
| 🛞 **Estado de gomas** | Monitoreo del desgaste y fechas de reemplazo |
| 💰 **Gastos e ingresos** | Dashboard financiero asociado a cada vehículo |
| 📰 **Noticias automotrices** | Feed con las últimas noticias del mundo automotriz |
| 💬 **Foro comunitario** | Espacio para que los usuarios compartan experiencias |
| 🎬 **Videos educativos** | Contenido multimedia sobre mantenimiento y mecánica |
| 🔍 **Catálogo de vehículos** | Explorador de modelos y especificaciones técnicas |

## 🚀 Instalación y ejecución local

### Prerrequisitos

- [Flutter SDK](https://docs.flutter.dev/get-started/install) >= 3.0.0
- [Android Studio](https://developer.android.com/studio) o [VS Code](https://code.visualstudio.com/) con extensión Flutter
- Un dispositivo físico o emulador configurado

### Pasos

```bash
# 1. Clonar el repositorio
git clone https://github.com/FJSaladin/Proyecto-Final---AutoZone.git

# 2. Entrar al directorio
cd Proyecto-Final---AutoZone

# 3. Instalar dependencias
flutter pub get

# 4. Ejecutar la app
flutter run
```
